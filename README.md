# 52-webscraper-capstone_zillow
Day 53/100 Udemy Python course. Webscraper python capstone project.
Wrapping up webscraping section of course. ~10 Days. Using bs4 
and selenium. 

Purpose of Project: To practice real life examples of webscraping,
and automation of jobs and applications.

Project scrapes practice zillow site, and then takes (address, cost, link)
and fills out a google form that is linked to a spreadsheet.
Workers/Clients can then view that spreadsheet to get data.
